# Project change journal

This directory records the dated engineering reasoning trail for `wb-ozon-card-migrator`.
It complements `CHANGELOG.md`, Git history, architecture and recovery docs.

Each substantive change uses `YYYY-MM-DD-short-slug.md` and the headings
`Date`, `Why`, `What`, `How`, `Verification` and `State`. Reference
Task cards, `plan_id`, `run_id`, artifacts and commits. Never include secrets,
private data, raw marketplace responses, full chat or tool transcripts. Correct
merged history with a new dated entry instead of silently rewriting it.
