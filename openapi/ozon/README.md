# Снимки документации Ozon

Сюда помещаются файлы `ozon-openapi-export-*.json` и
`ozon-openapi-diagnostic-*.json`, полученные с помощью
`tools/export_ozon_openapi.js`.

Правила:

- не перезаписывать старый снимок;
- не класть сюда cookies, `Client-Id`, API-ключи или ответы кабинета;
- сохранять дату получения в имени файла;
- до реализации клиента сверять количество методов и хеш схемы;
- методы записи не включать автоматически после обновления документации.
